# Karriere-Simulator

Textbasierter Fußball-Karriere-Simulator als mobile PWA (React + Vite + TypeScript).
Konzept und Fahrplan: [docs/KONZEPT.md](docs/KONZEPT.md).

```bash
npm install
npm run dev        # Entwicklungsserver
npm test           # Unit-Tests (Vitest)
npm run build      # Typecheck + Produktions-Build inkl. PWA
```
